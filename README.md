# Kiev mosquito screens pilot

Astro pilot project for a Kyiv-focused mosquito screens SEO site and calculator.

## Working model

- `main` stays clean.
- Draft work happens in `init-astro-kyiv`.
- One SEO entity lives in one MDX file with `uk` and `ru` routes, metadata, content blocks, and calculator context.
- Kyiv is the fixed location; local SEO depth comes from districts, objects, services, mesh/protection intents, and articles.
- The calculator receives page context first. URL parameters are only an additional campaign/intent layer.
